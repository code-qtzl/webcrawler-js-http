# webcrawler-js-http

Project for using Javascript to handle http web crawling

```
git clone https://github.com/code-qtzl/webcrawler-js-http.git
npm install
```

### Dependencies: Jest, JSDOM

```
npm install jest
npm install jsdom
```

### Crawl a website

`npm start 'your_site_url'`

### Test scripts

`npm test`
