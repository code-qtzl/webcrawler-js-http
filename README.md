# webcrawler-js-http

A fun learning project that uses Javascript to handle http web crawling

## 🚀 Prerequisites

-   **Node.js:** Ensure you have Node.js installed on your system. You can download it from [https://nodejs.org/](https://nodejs.org/).

## 🛠️ Installation

1. Clone the repository:

```
git clone https://github.com/code-qtzl/webcrawler-js-http.git
```

2.  Navigate to project directory:

```
cd webcrawler-js-http
```

3. Install dependencies: [Jest](https://jestjs.io/), [JSDOM](https://github.com/jsdom/jsdom)

```
npm install
```

4. Start Crawling

```
npm start 'your_site_url'
```

## Troubleshooting

If you encounter any issues during installation:

1. Make sure your Node.js and npm versions are up to date
2. Try clearing npm cache:
    ```bash
    npm cache clean --force
    ```
3. If modules are not installing correctly, delete `node_modules` folder and run:
    ```bash
    npm install
    ```
4. You can reach out! I learned cool stuff with this project 😁
